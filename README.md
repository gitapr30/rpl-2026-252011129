## Deskripsi Repository

Repository ini dibuat untuk menyimpan tugas, dokumentasi, dan hasil pembelajaran mata kuliah Rekayasa Perangkat Lunak (RPL).

Melalui repository ini, saya belajar bahwa pengembangan perangkat lunak tidak hanya berfokus pada penulisan kode, tetapi juga mencakup pemahaman kebutuhan pengguna, perencanaan, pengujian, dokumentasi, dan pemeliharaan sistem.

## Tujuan Pembelajaran

1. Memahami perbedaan antara pemrograman dan rekayasa perangkat lunak.
2. Memahami empat sudut pandang RPL, yaitu People, Product, Process, dan Quality.
3. Mampu mengidentifikasi permasalahan perangkat lunak berdasarkan hasil pengamatan dan bukti.
4. Mempelajari penggunaan Git dan GitHub untuk mengelola perubahan file.
5. Membiasakan dokumentasi dan penerapan etika profesional dalam pengerjaan proyek.
6. Menggunakan AI secara bertanggung jawab sebagai alat bantu pembelajaran.

## Catatan Keputusan Teknis

### 1. Pemilihan GitHub dan Markdown

Saya memilih GitHub sebagai media penyimpanan tugas karena Git dapat mencatat riwayat perubahan file secara bertahap. Hal ini memudahkan saya untuk melihat perkembangan pekerjaan dan memperbaiki kesalahan tanpa kehilangan riwayat sebelumnya.

Dokumentasi ditulis menggunakan Markdown karena formatnya sederhana, mudah dibaca, dan dapat ditampilkan langsung di GitHub.
